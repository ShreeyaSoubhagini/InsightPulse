# 📊 InsightPulse — E-Commerce Customer Voice Analytics

InsightPulse is an interactive data analytics project built to analyze customer reviews from an e-commerce clothing dataset.

The project focuses on understanding customer satisfaction, product/category performance, recommendation behavior, and common customer pain points using Python, SQL, NLP-based text analysis, and an interactive Streamlit dashboard.

---

## 🎯 Project Objective

The objective of InsightPulse is to answer business-oriented questions such as:

- How satisfied are customers overall?
- Which departments perform better?
- Which areas receive the most negative feedback?
- What are the most common customer pain points?
- How are return-related experiences associated with customer satisfaction?
- Which products/categories may require further attention?

---

## 🛠️ Technologies Used

- **Python**
- **Pandas** — Data cleaning and analysis
- **NumPy** — Numerical operations
- **Matplotlib / Seaborn** — Exploratory analysis
- **SQLite** — SQL-based analysis and querying
- **Plotly** — Interactive visualizations
- **Streamlit** — Interactive dashboard
- **NLP / Text Processing** — Review cleaning and keyword-based theme analysis
- **Jupyter Notebook** — Analysis and experimentation

---

## 📂 Dataset

The project uses the **Women's E-Commerce Clothing Reviews** dataset.

The dataset contains customer review information including:

- Age
- Rating
- Recommendation status
- Review title
- Review text
- Positive feedback count
- Department
- Clothing class
- Clothing ID

The dataset contains **23,486 customer reviews** across multiple clothing categories.
